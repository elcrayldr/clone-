# CRAY LDR — DRUMKIT CLONE

Windows x64 VST3 drum-kit extraction and sampler project.

## Current development status

**Milestone 0.1 — JUCE/VST3 foundation**

This repository contains the initial JUCE 8.0.6 CMake project, a 64-pad MIDI note layout (notes 36–99), a basic procedural drum voice engine, and a Windows GitHub Actions build workflow.

This is an engineering foundation, **not the finished Drumkit Clone product**. Audio-file import, transient extraction, source separation, AI classification, sample editing, and WAV/MIDI kit export are not implemented yet.

## Target product

- Import full songs and instrumentals (WAV, AIFF, MP3).
- FAST mode: DSP transient detection and segmentation.
- AI mode: local neural drum/percussion source separation, followed by detection.
- Classify and group kicks, snares, claps, hats, toms, percussion, and cymbals.
- 64 pads across four banks, MIDI notes 36–99.
- Per-pad sample editing, velocity, choke groups, and audition.
- Export individual WAV files, complete kits, and MIDI patterns.
- Offline operation after model/runtime installation.

## Build requirements

- Windows 10/11 x64
- Visual Studio 2022 with **Desktop development with C++**
- CMake 3.22 or newer
- Git
- Internet access on first configure to fetch JUCE 8.0.6

## Build

From a Visual Studio 2022 Developer PowerShell:

```powershell
cmake -S . -B build -A x64 -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel
```

The VST3 target is generated by JUCE under the build artefacts directory. GitHub Actions also builds the project on Windows and publishes a VST3 artifact when the build succeeds.

## Architecture direction

The extraction pipeline is intentionally separated into stages:

1. Audio import and decoding
2. Optional local AI source separation
3. Transient/onset detection
4. Feature extraction and drum-family classification
5. Similarity clustering and variation grouping
6. Sample reconstruction and editing
7. MIDI sampler and kit export

AI separation must not be represented as simple slicing. Model licensing, redistribution rights, runtime footprint, and offline inference performance must be checked before selecting and bundling a model.

## Compatibility target

FL Studio 26 and Cubase 13 on Windows x64. Compatibility is not claimed until tested in both hosts.
